# Git Commit Policy

- **Luôn luôn tạo commit cục bộ (Local Commit)** sau khi hoàn thành bất kỳ tính năng, yêu cầu sửa đổi, tối ưu hay cập nhật nào.
- **TUYỆT ĐỐI KHÔNG TỰ Ý PUSH** code lên origin/remote repository mà không có sự đồng ý hoặc yêu cầu rõ ràng từ người dùng.
- Mọi quy trình tự động chỉ được phép dừng ở bước `git commit`, không được thực hiện `git push`.
